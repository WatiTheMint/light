# Пока горит свет

Маленькая игра в одну краску. Смотрительнице маяка на мысе Тихом осталось пять ночей до того, как фонарь переведут на автоматику. Лучом надо вести рыбацкие лодки домой сквозь туман и мимо скал, а между ночами читать её дневник.

Игра работает в браузере, без сборки и без зависимостей.

## Управление

- **Мышь или палец** направляют луч. Чем дальше от маяка указываешь, тем длиннее и уже луч.
- **Пробел**, правая кнопка мыши или кнопка внизу слева включают ревун (с четвёртой ночи).
- **Стрелки** или **WASD** тоже двигают луч.
- **M** включает и выключает звук, **Esc** ставит паузу.

## Как запустить у себя

- **Двойной щелчок по `index.html`.** Игра работает, но фоновая музыка играет без эффектов: с `file://` браузер не даёт обрабатывать звук.
- **Через локальный сервер** всё работает полностью. Нужен Node.js:

  ```
  node serve.js
  ```

  Потом открыть http://127.0.0.1:5185

## Как выложить на GitHub Pages

1. Создай репозиторий и загрузи в его корень **содержимое** папки: `index.html`, `css/`, `js/`, `audio/` и остальные файлы.
2. Открой **Settings → Pages**. В разделе **Build and deployment** выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, потом нажми **Save**.
3. Через минуту-две игра откроется по адресу `https://<твой-ник>.github.io/<имя-репозитория>/`.

## Что где лежит

| Файл | Что внутри |
| --- | --- |
| `js/story.js` | Все тексты: дневник, подсказки, имена лодок, состав каждой ночи |
| `js/world.js` | Логика: луч, лодки, скалы, причал. Баланс в объекте `TUNE` |
| `js/render.js` | Рисование ночи на canvas |
| `js/audio.js` | Звук: море, колокольчики, ревун и фоновая музыка с эффектами |
| `js/main.js` | Экраны, управление, сохранение прогресса |
| `css/style.css` | Оформление экранов и дневника |
| `audio/lullaby.mp3` | Кавер Stranded Lullaby, фоновая музыка |
| `serve.js` | Локальный сервер для запуска |
| `build.js` | Сборка в один HTML-файл для публикации на claude.ai. Для GitHub не нужна |

Прогресс сохраняется в браузере (localStorage, ключи `pgs:*`).
